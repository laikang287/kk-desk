# KK Desk

[English](../README.md) · [简体中文](../README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

KK Desk 是一款適用於 Windows 10/11 的快捷啟動工具，會與桌面即時同步，讓您無須返回桌面即可直接開啟桌面捷徑。

## 核心功能

1. **與桌面捷徑即時同步，無須返回桌面即可啟動程式。** 當您在多個視窗或多個螢幕上安排工作時，按下 Win+D 返回桌面可能會打亂視窗配置。使用 KK Desk 開啟桌面捷徑，可以保留目前的工作配置。
2. **將桌面捷徑分類整理。** 尚未分類的桌面捷徑會顯示在內建的「預設」子分類中。您可以在「桌面」分類下新增子分類並移入捷徑。分類僅在 KK Desk 內生效，不會變更實際桌面。

相較於上游 v1.5.2，本分支新增桌面關聯與桌面捷徑即時同步，支援多種介面語言，並將捷徑右鍵選單調整為與 Windows 11 桌面選單一致，也包含其他改進。

請從[版本發布頁面](https://github.com/laikang287/kk-desk/releases)下載免安裝版。執行時產生的設定資料會儲存在程式同層的 `data` 資料夾中。
