# KK Desk

[English](../README.md) · [简体中文](../README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

KK Desk ist ein Schnellstarter für Windows 10/11. Er wird in Echtzeit mit dem Desktop synchronisiert und kann Desktop-Verknüpfungen direkt öffnen, ohne zum Desktop zurückzukehren.

## Hauptfunktionen

1. **Desktop-Verknüpfungen in Echtzeit synchronisieren und starten, ohne geöffnete Fenster zu minimieren.** Bei vielen Fenstern auf einem oder mehreren Monitoren kann Win+D die Anordnung stören. Mit KK Desk öffnen Sie Verknüpfungen und behalten Ihren Arbeitsbereich bei.
2. **Desktop-Verknüpfungen kategorisieren.** Nicht zugeordnete Verknüpfungen erscheinen in der integrierten Unterkategorie „Standard“. Erstellen Sie Unterkategorien in der Kategorie „Desktop“ und verschieben Sie Verknüpfungen dorthin. Die Sortierung gilt nur in KK Desk und verändert den tatsächlichen Desktop nicht.

## Projektursprung

Dieses Projekt ist ein inoffizieller Fork von [Dawn Launcher](https://github.com/fanchenio/DawnLauncher) **v1.5.2** ([Upstream-Version](https://github.com/fanchenio/DawnLauncher/releases/tag/1.5.2), entsprechend dem historischen Commit `ac36714` in diesem Repository). Es wird unabhängig gepflegt und ist weder mit dem Originalprojekt verbunden noch offiziell von ihm unterstützt.

Gegenüber Upstream v1.5.2 ergänzt dieser Fork die Desktop-Verknüpfung und deren Live-Synchronisierung, unterstützt mehrere Oberflächensprachen, passt das Kontextmenü an das Windows-11-Desktopmenü an und enthält weitere Verbesserungen.

Nicht hier beschriebene Funktionen stammen aus dem Upstream-Projekt. Siehe die erhaltene [chinesische Upstream-Dokumentation](../upstream/README.md) und [englische Upstream-Dokumentation](../upstream/README-ENGLISH.md).

## Installation

Laden Sie eine portable Version von der [Release-Seite](https://github.com/laikang287/kk-desk/releases) herunter. Laufzeit-Konfigurationsdaten werden im Ordner `data` neben der Anwendung gespeichert.
