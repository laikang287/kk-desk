# KK Desk

[English](../README.md) · [简体中文](../README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

KK Desk は Windows 10/11 向けのランチャーです。デスクトップとリアルタイムに同期し、デスクトップに戻らずショートカットを直接起動できます。

## 主な機能

1. **デスクトップのショートカットと同期し、開いているウィンドウをそのままにして起動できます。** 複数のウィンドウやモニターで作業中に Win+D でデスクトップへ戻ると、ウィンドウ配置が崩れることがあります。KK Desk から起動すれば現在の配置を保てます。
2. **デスクトップのショートカットを分類できます。** 未分類のショートカットは組み込みの「既定」サブカテゴリに表示されます。「デスクトップ」カテゴリにサブカテゴリを作成し、ショートカットを移動できます。この分類は KK Desk 内だけに適用され、実際のデスクトップは変更されません。

## プロジェクトの由来

本プロジェクトは [Dawn Launcher](https://github.com/fanchenio/DawnLauncher) **v1.5.2** から派生した非公式フォークです（[上流リリース](https://github.com/fanchenio/DawnLauncher/releases/tag/1.5.2)、本リポジトリの履歴コミット `ac36714` に相当）。独立して保守されており、元プロジェクトとの提携や公式な推奨関係はありません。

上流 v1.5.2 と比べ、デスクトップ連携とショートカットのリアルタイム同期、多言語 UI、Windows 11 のデスクトップに合わせた右クリックメニューなどを追加・変更しています。

ここに記載されていない機能は上流から引き継いでいます。[上流の中国語ドキュメント](../upstream/README.md)と[上流の英語ドキュメント](../upstream/README-ENGLISH.md)をご覧ください。

## インストール

[リリースページ](https://github.com/laikang287/kk-desk/releases)からポータブル版をダウンロードしてください。実行時の設定データはアプリと同じ場所にある `data` フォルダーに保存されます。
