# KK Desk

[English](../README.md) · [简体中文](../README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

KK Desk — лаунчер для Windows 10/11, который синхронизируется с рабочим столом в реальном времени и позволяет запускать ярлыки, не возвращаясь на рабочий стол.

## Основные возможности

1. **Синхронизация ярлыков рабочего стола и запуск без сворачивания открытых окон.** При работе с множеством окон на одном или нескольких мониторах сочетание Win+D может нарушить их расположение. KK Desk позволяет запускать ярлыки, сохраняя рабочую область.
2. **Группировка ярлыков рабочего стола по категориям.** Ярлыки без категории отображаются во встроенной подкатегории «По умолчанию». Создавайте подкатегории в категории «Рабочий стол» и перемещайте туда ярлыки. Группировка действует только в KK Desk и не меняет настоящий рабочий стол.

## Происхождение проекта

Проект является неофициальным форком [Dawn Launcher](https://github.com/fanchenio/DawnLauncher) **v1.5.2** ([версия upstream](https://github.com/fanchenio/DawnLauncher/releases/tag/1.5.2), соответствует историческому коммиту `ac36714` в этом репозитории). Он развивается независимо, не связан с исходным проектом и не имеет его официального одобрения.

По сравнению с upstream v1.5.2 добавлены связь с рабочим столом и синхронизация ярлыков в реальном времени, поддержка нескольких языков интерфейса и контекстное меню ярлыков в стиле рабочего стола Windows 11, а также другие улучшения.

Функции, не описанные здесь, унаследованы от upstream. См. сохранённую [документацию upstream на китайском](../upstream/README.md) и [на английском](../upstream/README-ENGLISH.md).

## Установка

Загрузите портативную версию со [страницы релизов](https://github.com/laikang287/kk-desk/releases). Данные конфигурации сохраняются в папке `data` рядом с приложением.
