# KK Desk

[English](../README.md) · [简体中文](../README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

KK Desk는 Windows 10/11용 빠른 실행 도구입니다. 바탕 화면과 실시간으로 동기화되어 바탕 화면으로 돌아가지 않고도 바로 가기를 실행할 수 있습니다.

## 주요 기능

1. **바탕 화면 바로 가기와 실시간 동기화하여 열려 있는 창을 유지한 채 실행합니다.** 여러 창이나 여러 모니터에서 작업할 때 Win+D로 바탕 화면으로 돌아가면 창 배치가 흐트러질 수 있습니다. KK Desk에서 바로 가기를 실행하면 현재 작업 배치를 유지할 수 있습니다.
2. **바탕 화면 바로 가기를 분류합니다.** 분류되지 않은 바로 가기는 기본 제공되는 ‘기본’ 하위 분류에 표시됩니다. ‘바탕 화면’ 분류 아래 하위 분류를 만들고 바로 가기를 이동하세요. 이 분류는 KK Desk 안에서만 적용되며 실제 바탕 화면은 변경하지 않습니다.

## 프로젝트 출처

이 프로젝트는 [Dawn Launcher](https://github.com/fanchenio/DawnLauncher) **v1.5.2**의 비공식 포크입니다([업스트림 릴리스](https://github.com/fanchenio/DawnLauncher/releases/tag/1.5.2), 이 저장소의 과거 커밋 `ac36714`에 해당). 독립적으로 유지 관리되며 원 프로젝트와 제휴하거나 공식 승인을 받은 프로젝트가 아닙니다.

업스트림 v1.5.2에 비해 바탕 화면 연결 및 바로 가기 실시간 동기화, 다국어 인터페이스, Windows 11 바탕 화면과 일치하는 바로 가기 컨텍스트 메뉴 등을 추가하거나 변경했습니다.

여기에 설명되지 않은 기능은 업스트림에서 이어받았습니다. 보존된 [업스트림 중국어 문서](../upstream/README.md)와 [업스트림 영어 문서](../upstream/README-ENGLISH.md)를 참고하세요.
